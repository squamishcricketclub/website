# Minimal Squamish Cricket Club website

## Update club information
Edit only `assets/site-data.js` for routine updates to contact details, address, society status, board, fees, registration link, social links and schedules.

Core mission and program descriptions remain in the HTML so essential nonprofit information is available even if JavaScript fails.

## Upload
Upload all files and the `assets` folder to the repository root. Keep `CNAME` in the root. Do not upload the ZIP itself.
